# 真平台語電子書・giú大索搶答大賽 (Giú-tuā-soh Pí-sài)

依照真平台語電子書（國小一年級～六年級、上下學期共 12 冊）製作的線上教學競賽遊戲。

## 主要功能

- **分年級、分冊與全冊／分課練習**：涵蓋國小 1～6 年級上下學期共 12 冊（58 課），**每課皆收錄 12 題核心語詞**（全題庫近 700 詞），可選擇「全本書綜合練習」或「分課單／複選練習」。
- **不重複洗牌出題機制**：採用不重複洗牌題庫（Shuffle Deck），確保該輪題庫出完前不重複出題，避免連續遇到相同題目。
- **臺羅羅馬字 ＆ 台語漢字雙向練習**：支援「羅馬字＋漢字同顯」、「羅馬字按鈕／漢字按鈕分區」、「看漢字搶答羅馬字」、「看羅馬字搶答漢字」四種模式。
- **giú大索雙隊搶答競賽**：支援雙人／兩隊同螢幕觸控或鍵盤（`A/S/D/F` vs `J/K/L/;`）搶答，亦可單人挑戰電腦隊伍；可自訂總時間限制、單題倒數與獲勝格數。
- **贏方顯示臺羅羅馬字**：每回合搶答成功與最終勝負揭曉時，會在贏的那一方醒目顯示臺羅羅馬字歡呼與搶答語詞。
- **護眼莫蘭迪柔和配色 ＋ 粉圓體**：採用柔和不刺眼的燕麥奶白、珊瑚粉與鼠尾草綠配色，搭配 `jf-openhuninn` 開放粉圓字體。

## 線上使用

直接開啟 `index.html` 或啟用 GitHub Pages 即可於瀏覽器遊玩。
